# **App Name**: Cricket Oracle

## Core Features:

- Match Outcome Prediction: Predict IPL match outcomes using an ensemble machine learning model incorporating various algorithms and feature engineering pipelines. The model will take into account team momentum and player performance trends.
- LLM Reasoning: Integrate a local LLM (using Ollama) to provide reasoning and explain predictions, highlighting key factors influencing the outcome. The LLM will act as a tool that provides additional insights.
- Interactive Dashboard: Design a responsive frontend using React.js to display match predictions, key player performance trends, and LLM-generated insights.

## Style Guidelines:

- Primary color: Dark green (#1B5E20) to evoke a sense of expertise and reliability.
- Secondary color: Light gray (#EEEEEE) for backgrounds to ensure readability.
- Accent: Bright yellow (#FFEB3B) to highlight key predictions and insights.
- Clean and modern typography for clear data presentation.
- Use cricket-related icons to represent teams, players, and match events.
- Dashboard-style layout for easy access to predictions, visualizations, and LLM insights.
- Subtle animations for loading predictions and updating match data in real-time.
